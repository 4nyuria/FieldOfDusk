# Action RPG

> A 2D Action RPG developed in Java, based on the RPG development tutorial by RyiSnow.

---

## About the Project

This project is a 2D Action RPG developed as part of my journey into game development and software development.

The current version follows the **RyiSnow RPG tutorial**, which I am using as a foundation to learn and implement the core systems of the game.

At the moment, I am working on the **item system**.

---

## Current Progress

- Player movement
- World and map system
- Basic RPG systems
- Item system — In progress

---

## Goals

The main goal is to complete the RyiSnow tutorial and then continue expanding the project with my own mechanics and ideas.

### Planned Features

- Complete item system
- Turn-based combat system
- Enemies and bosses
- HP and combat mechanics
- Story and events
- Player choices and multiple outcomes

The final goal is to combine the **real-time exploration of an Action RPG** with a **turn-based combat system**, creating a hybrid gameplay experience.

- Java
